# 创意工作台使用说明

先选择作品类型，描述目标，收到结果后围绕结果修改。文化资料、图片和详细设定按需补充，不必先填完每个阶段。

## 制作网站

1. 首页选择“做一个网站”，填写项目名称和网站目标。
2. 在“查看资料与默认选择”中核对文化资料和主题插画，再点“开始制作网站”。
3. 如果出现“复制请求到 WorkBuddy”，复制完整内容，交给已经连接工作台的 WorkBuddy。它应接续原任务，实现网站后回传真实源码 ZIP。
4. 初稿出现后，切换电脑与手机预览，实际操作导航、筛选、FAQ 等交互。
5. 在“哪里需要调整？”选择范围，说明这轮变化，点“按此要求修改”。无需重新描述所有要求；网站可以直接修改尚未确认的初稿。
6. 满意后点“使用这个版本”，再下载正在预览版本的网站源码 ZIP。

需求应说明受众、栏目、实际功能和视觉偏好。例如：制作一个岭南手作文化专题网站，包含文化卡片、类别筛选、个人探索清单及出处，手机和电脑均可浏览。使用项目已有插画，虚构体验标明演示，不接入真实预约或支付。

网站任务先准备需求和素材，收到实际源码才会出现初稿。需求包不等于网站。已有本轮源码但页面仍等待时，可使用“导入本次网站结果”；不要为此再建项目。

等待修改结果时，可以先写下一轮要求。必须先完成或结束本轮等待，才能再次提交。“结束本次等待”不会自动停止 WorkBuddy 中的工作。

默认交付静态网站。下载后完整解压并按运行说明检查。公网发布、真实用户账户、预约、支付和业务后台需要另行接入。

## 文化依据与跨媒介资料

网站在“本次目标与资料”查看已使用条目。打开详细编辑，在“确定创意”中选择文化资料，核对地域、出处及使用边界；“当前项目的文化语境”可保存时代与虚构设定。

“选择主题视觉素材”可把本机生成的原创插画及对应依据加入作品。只选择知识条目不会自动生成新图片。插画不能作为实景或文物复原的证明。

需要把故事或视频带入网站时，先采用来源作品，再切换网站类型，在详细编辑的“资料继承与历史版本”选择来源及媒体。原类型草稿保留；切换类型本身不代表已引用全部内容。回传网站后，检查所选正文与文件确实出现在网站里。

## 小说

首页选择“写一篇故事”，填写故事目标并生成初稿。未配置网页文字服务时，可以“交给 WorkBuddy 写作”，让其将完整正文写回同一项目。

网页候选正文需先“使用这个版本”，才能据此继续修改。主页面下载 Markdown；TXT 和已采用正文编辑在详细编辑的“制作与交付”。当前支持短篇，不提供长篇自动编排。

## 美术与图片

“设定画风”编辑一段美术风格提示词，修改后用于后续新图；生成候选提示词时，比较并采用后才替换当前稿。实际图片在“准备图片”中制作。

添加人物、场景或物件对象，写清形象及用途，按需选择参考图片，再提交生成。新图会显示在对象卡片，检查后点击“选用此图”。修改已有图片时说明变化位置和保留内容，对比原图与候选，再完成选用。

文件已入库或任务成功，不等于最终选用。使用 WorkBuddy 时，必须把结果回传网页创建的原任务；单独把图片导入媒体库不能完成原交接。页面有补交入口时，可将已生成的对应图片交回原任务。

## 视频

首页选择“做一段视频”，描述一个连续镜头，核对横屏 16:9 或竖屏 9:16，以及 2–10 秒时长。需要首帧时进入详细编辑选择真实图片，再生成镜头。

收到 MP4 后实际播放，检查宽高、时长和运动效果，再使用该版本。规格未通过时不能仅凭能播放就当作合格成果。修改要求会用于下一次生成，不是直接编辑 MP4 时间轴。分镜、声音和合成在详细编辑中按需使用。

## 三维资产与图案

本机需安装 Blender。首页选择“生成 3D 文创资产”，描述器物或建筑构件，点击“开始生成资产”。文字服务解析受限方案，或由 WorkBuddy 交回原任务方案；本机脚本据此构造和检查模型。

当前支持碗、盘、盆、花瓶、罐、锅、瓢勺、茶壶，以及简化骑楼、花窗、柱廊和屋顶。不同结构支持不同参数，不提供任意雕塑、复杂浮雕、照片建模或网页直接编辑。

成功后自动显示模型，可拖动旋转、滚轮缩放，下载 Blender 文件或 GLB。勾选“物品自动旋转展示”会以略高的固定视角展示旋转物体，手动调整会停止。修改需求后生成新版本，旧模型保留。

在支持的器皿模型下点击“生成文化图案”，图片服务生成平面 PNG，本机继续贴合外壁并导出新模型。收到 PNG 只是中间步骤，要等模型完成。此功能保留器形与内部结构，支持八类内置器皿，暂不支持建筑或任意导入模型，也不自动把模型嵌入网站。

## 配置与恢复

“设置 → API 配置”中的 API 地址、模型名称和密钥必须匹配。保存配置不等于鉴权通过，也不会改写旧任务的失败记录；更新后需明确发起新任务。

等待交接时继续原任务。提交结果不确定时先“核对上次提交”，不要连续创建付费请求。刷新只查询原状态；文字请求中断后不会靠刷新重新发送。无法联网时检查后台服务的运行账户与网络权限，而不只是浏览器或 VPN。

结果提示依据变化时，保留旧文件并核对新的目标、资料或参考，避免旧结果覆盖新要求。发生错误时记录操作、时间、项目及任务标识、页面错误；不要附密钥。

## 保存与备份

确认页面显示“已保存到本机服务”再关闭。“临时体验”不持久保存。同一服务的数据可跨浏览器读取，不会自动同步到另一台机器。

在“设置 → 项目与文件”导出全部项目备份。导入会创建独立项目，原项目保留。较大项目按容量提示停止服务后复制完整数据目录，默认是 `work/data/`；仅复制 workspace.json 不包含全部成品。

配置文件可能含密钥，不要放入公开仓库或演示下载包。清理前先使用 `storage_cleanup` 预览，仅在确认后删除工具认定的冗余副本；不要手动整批删除任务和交接目录。
