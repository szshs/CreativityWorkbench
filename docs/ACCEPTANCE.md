# 功能验收清单

在独立测试项目中逐项检查，记录通过、失败、阻塞或未测。缺少实际模型服务时记为阻塞；不以模拟图片或占位文件代替生成结果。

| 范围 | 操作与通过标准 |
| --- | --- |
| 启动 | 首页、项目和设置可打开，项目保存后重新进入仍存在 |
| 配置 | 保存后用于新请求，密钥不回显，平台地址与模型一致 |
| 主题知识 | 搜索并选用资料，能查看出处、地域和使用边界 |
| 主题素材 | 新安装生成内置文件，加入作品后可预览并进入网站任务包 |
| 小说 | 完整正文写回原项目，导出 TXT 或 Markdown，标题无重复 |
| 图片 | 原任务接收真实 PNG，对象卡片展示，选用后重新进入仍一致 |
| 原图修改 | 实际对比变化与应保留部分，完成比较记录后可选用 |
| 视频 | MP4 可播放，实际比例和时长符合要求；不合格文件不能冒充通过 |
| 网站 | 一次目标创建任务，接续原任务回传真实源码并自动展示初稿 |
| 网站修改 | 选择范围并提交修改，交接入口可见，新版沿用旧源码且保留历史 |
| 网站交互 | FAQ 展开、收起、再次展开；导航、筛选、空状态、键盘和手机布局均可用 |
| 网站交付 | 使用目标版本，下载 ZIP，完整解压后按说明运行并复测 |
| 跨媒介 | 明确选择完整正文和已采用媒体，实际文件与来源进入网站任务 |
| 三维模型 | 受控造型产生真实 Blender 与 GLB，网页显示且下载后可重开 |
| 三维图案 | 原任务收到 PNG 后继续贴图，器形与内壁保持，贴图随模型文件保存 |
| 三维查看 | 自动旋转可开启，手动调整停止，历史预览不覆盖当前结果 |
| 恢复 | 原请求重试不重复创建，取消或旧任务晚到不覆盖新作品 |
| 备份 | 导出并导入为独立项目，正文、媒体和模型仍可读取 |
| WorkBuddy | 两项 Skills 实际导入，MCP 可发现并调用，回传原任务后网页可操作 |

检查程序文件存在、HTTP 返回成功或任务标记成功，只覆盖相应环节。作品内容、媒体质量和网站交互仍需查看实际输出。

遇到问题时记录项目、任务 ID、操作顺序、预期及实际结果，并注明是网页、WorkBuddy、模拟接口还是真实供应商。截图和记录不包含密钥。
